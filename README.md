# Pasos para la instalación del entorno virtual

1. Ejecutar comando python -m .venv .venv
2. Ejecutar comando .venv\Scripts\Activate
3. crear archivo en la raíz del proyecto .env y configurar los campos que vienen en el de ejemplo. (.env.example)
4. Instalar dependencias con el comando pip install -r requirements.txt
5. Por último crear una carpeta con el nombre de "csv" y añadir el archivo csv que se utilizará para el proyecto.
